1. github.com par account banao / login karo
2. New Repository banao, naam: digital-store-bot, Public mat karo - Private rakho

STEP 2 - KOYEB PAR FREE HOST KARO (Phone se, Chrome me)
1. koyeb.com par Gmail se login karo
2. Create Service > GitHub > apna repo select karo
3. Build: Node.js, Run command: npm start
4. Environment Variables > Add:

   Value: tumhara BotFather wala token (Telegram me @BotFather se mila tha)
5. Deploy dabao. 2-3 minute me bot online ho jayega.
